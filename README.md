# 소은이의 영어단어 시험 화이팅♥

개인용 초등 고학년 영어단어 학습 목록/시험/기록 웹앱입니다.

## 핵심 기능

- 버튼으로 새 주간 영어단어 100개 생성
- 한 화면에서 영어 + 한글 뜻 전체 목록 확인
- 목록 직접 수정 및 개별 단어 교체
- 한글 → 영어 Spelling Test 100문제
- 영어 → 한글 Meaning Test 100문제
- 자동 채점 및 오답 표시
- 시험 시작 후 단어 목록/기록/관리 메뉴 잠금 (새로고침 후에도 시험 모드 유지)
- 날짜별 시험 기록 저장
- JSON 백업/복원
- PWA 홈 화면 설치 지원
- 서비스 워커 캐시를 통한 오프라인 실행 지원
- 로그인, 서버, 데이터베이스, 인쇄 기능 없음

## 노트북에서 바로 실행

`index.html` 파일을 브라우저에서 직접 열어도 기존 기능은 정상 동작합니다.

단, PWA 설치와 오프라인 캐시는 `file://` 방식이 아니라 GitHub Pages 같은 HTTPS 주소에서 작동합니다.

## GitHub Pages 배포

아래 파일과 폴더를 GitHub 저장소 최상위에 그대로 업로드합니다.

- `index.html`
- `styles.css`
- `words.js`
- `app.js`
- `manifest.webmanifest`
- `service-worker.js`
- `icons/`

기존 GitHub Pages 저장소를 사용 중이면 위 파일로 덮어쓰면 됩니다.

## iPhone / iPad 홈 화면에 앱으로 추가

1. Safari에서 GitHub Pages URL을 엽니다.
2. 공유 버튼을 누릅니다.
3. `홈 화면에 추가`를 선택합니다.
4. 가능한 경우 `웹 앱으로 열기`를 활성화하고 추가합니다.
5. 이후 홈 화면의 `소은 영어단어` 아이콘으로 실행합니다.

PWA는 GitHub Pages URL을 기반으로 실행되며 별도 App Store 등록이나 비용이 필요하지 않습니다.

## 오프라인 사용

GitHub Pages에서 한 번 정상적으로 실행하면 핵심 HTML/CSS/JS와 아이콘이 캐시에 저장됩니다. 이후 네트워크가 없어도 이전에 설치/로딩된 앱을 실행할 수 있습니다.

앱 코드를 GitHub에서 수정한 경우 인터넷에 연결된 상태에서 앱을 다시 실행하거나 새로고침하면 최신 파일을 가져옵니다.

## 데이터 저장

모든 학습 데이터는 브라우저의 `localStorage`에 저장됩니다.

- 같은 브라우저/설치된 웹앱에서는 새로고침이나 기기 재부팅 후에도 유지됩니다.
- iPad와 노트북 간 자동 동기화는 되지 않습니다.
- 다른 기기로 옮길 때 `관리 > 백업 다운로드 / 백업 복원`을 사용합니다.

## 파일 구조

- `index.html` — 화면 구조 및 PWA 메타데이터
- `styles.css` — UI / 반응형 스타일
- `words.js` — 기본 단어 풀
- `app.js` — 목록 생성, 시험, 채점, 기록, 백업 및 PWA 등록 로직
- `manifest.webmanifest` — 홈 화면 앱 이름/아이콘/실행 방식
- `service-worker.js` — 오프라인 캐시
- `icons/` — 홈 화면/PWA 아이콘
