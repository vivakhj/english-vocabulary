# Weekly English Vocabulary

개인용 초등 고학년 영어단어 학습 목록/시험/기록 웹앱 MVP입니다.

## 핵심 기능

- 버튼으로 새 주간 영어단어 100개 생성
- 한 화면에서 영어 + 한글 뜻 전체 목록 확인
- 목록 직접 수정 및 개별 단어 교체
- 한글 → 영어 Spelling Test 100문제
- 영어 → 한글 Meaning Test 100문제
- 자동 채점 및 오답 표시
- 시험 시작 후 단어 목록/기록/관리 메뉴 잠금 (새로고침 후에도 시험 모드 유지)
- 날짜별 시험 기록 저장
- JSON 백업/복원
- 로그인, 서버, 데이터베이스, 인쇄 기능 없음

## 실행 방법

### 가장 간단한 방법

`index.html` 파일을 브라우저에서 직접 열어도 동작합니다.

### 로컬 웹서버로 실행

```bash
cd weekly-english-vocab
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080` 접속.

## 데이터 저장

모든 데이터는 브라우저의 `localStorage`에 저장됩니다.

- 같은 브라우저에서는 새로고침/재부팅 후에도 유지됩니다.
- iPad와 노트북 간 자동 동기화는 되지 않습니다.
- 다른 기기로 옮길 때 `관리 > 백업 다운로드 / 백업 복원`을 사용합니다.

## 파일 구조

- `index.html` — 화면 구조
- `styles.css` — UI / 반응형 스타일
- `words.js` — 기본 단어 풀
- `app.js` — 목록 생성, 시험, 채점, 기록, 백업 로직
